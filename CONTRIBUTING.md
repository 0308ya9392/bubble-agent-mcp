# Contributing

Thanks for helping improve Bubble Agent MCP.

## Development

1. Fork and clone the repository.
2. Install Node.js 20+ and pnpm.
3. Run `pnpm install`.
4. Create a focused branch.
5. Run `pnpm check` before opening a pull request.

## Scope

Good contributions improve MCP compatibility, input validation, output readability, tests, documentation, or security.

Keep scraping, private prompts, database access, scoring internals, and infrastructure credentials out of this package. Those belong behind the authenticated Bubble Agent API.

## Pull requests

- Keep changes focused.
- Add tests for behavior changes.
- Update README or examples when setup changes.
- Never include real API keys, project IDs, user data, or provider payloads.
